# Портфолио услуг

## Различать тип работы

- Демонстрационный проект: идея автора, не оплаченный заказ, результатов клиента нет.
- Клиентская работа: подтверждённый реальный заказ; раскрывать материалы только с разрешением.
- Разбор чужого сайта: наблюдаемые особенности и предложение улучшений, без притязания на авторство.

## Для сайтов

Проверять назначение, понятность предложения, мобильную версию, навигацию, рабочие ссылки, формы и реальное получение обращения, подключение домена, читаемость, базовую доступность и возможность передачи клиенту. Не вводить тестовую заявку на чужом действующем сайте без разрешения. Проверку производительности и поисковой индексации делать только доступными подходящими инструментами; не угадывать результаты.

Отдельно выяснить, что пользователь действительно предлагает: макет, лендинг, многостраничный сайт, магазин, интеграции или сопровождение. Не обещать платежи, безопасность, CRM, SEO или юридические документы, если это не входит в компетенции и объём работ. Для конкретной разработки использовать профильные навыки среды.

## Кейс

Контекст → задача → собственная работа → наглядный результат → ограничения → следующий шаг. Бизнес-результаты включать только с подтверждением и понятным периодом. Если данных нет, описывать сделанные улучшения, не рост конверсии.

## Демонстрационный Reel

Показать результат на телефоне, один пользовательский путь и существенную деталь реализации. Назвать для кого пример. Не строить весь ролик вокруг инструмента ИИ, если клиенту важен конечный результат. Указать, что проект демонстрационный, если это так.
