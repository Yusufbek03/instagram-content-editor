# Instagram Content Editor

Навык для ChatGPT/Codex по Instagram: контент, услуги, монетизация, продажи и подключение интеграций. Написан вручную, версия 2.0.

Работает **без аккаунта и сторонних скриптов** — 20 режимов на основе переданных тобой текстов, изображений, статистики и ссылок. Подключения к Instagram необязательны и делаются отдельно.

## Возможности

20 режимов, объединённых в две группы.

### Контент и редактура

| Режим | Что делает |
|---|---|
| `ig-profile` | Разбор и улучшение профиля: имя, описание, аватар, ссылки, закреплённые публикации |
| `ig-reel` | Сценарий короткого видео: три варианта начала, текст на экране, план кадров |
| `ig-viral` | Исследование примеров похожих авторов с источниками и датами наблюдения |
| `ig-caption` | Подпись: первая строка, продолжение, одно действие, хештеги по теме |
| `ig-carousel` | Карусель: обложка, контекст, шаги, итог, следующее действие |
| `ig-story` | Последовательность Stories: повод, содержание, взаимодействие, завершение |
| `ig-plan` | Контент-план с метрикой проверки и нужными материалами |
| `ig-human` | Редактура текста: ясность, голос автора, убрать лишнее |
| `ig-comment` | Черновики комментариев без спама и выдуманного опыта |
| `ig-reply` | Ответы на комментарии с разбором по типам |
| `ig-dm` | Черновик личного сообщения с понятным поводом |
| `ig-repurpose` | Переработка длинного материала в несколько форматов |
| `ig-audit` | Аналитика: наблюдения с доказательствами и проверяемые эксперименты |

### Бизнес и подключения

| Режим | Что делает |
|---|---|
| `ig-strategy` | Позиционирование, три тематические линии, план проверки на 2 недели |
| `ig-monetize` | Сравнение моделей заработка: услуги, продукты, реклама, партнёрства |
| `ig-offer` | Формулировка предложения: адресат, результат, состав, срок, ограничения |
| `ig-portfolio` | Кейсы и портфолио без подмены демо-проекта клиентским |
| `ig-sales` | Ответы на входящие, вопросы для брифа, черновик предложения |
| `ig-connect` | Проверка и подключение реально доступных интеграций |
| `ig-experiment` | Проверка гипотез: база, метрика, период, критерий решения |

> Обозначения `/ig-*` — текстовые названия режимов, а не зарегистрированные системные команды.

## Установка

**ChatGPT / Atlas:** загрузить папку навыка в интерфейсе.

**Codex:** скопировать папку в директорию навыков:

```bash
git clone https://github.com/Yusufbek03/instagram-content-editor.git
```

Затем указать навык как основной для задач Instagram.

## Принципы работы

Навык разделяет три вещи: наблюдаемые факты, твои слова и предположения. Недостающий факт помечается как `[уточнить факт]` или текст пишется без него.

Чего навык не делает:

- Не обещает рост, вирусность, продажи или конкретные охваты.
- Не выдумывает опыт, клиентов, результаты и цифры.
- Не выдаёт редакционную оценку за измеренную эффективность.
- Не считает малый объём данных доказанной закономерностью.
- По умолчанию готовит черновики — ничего не отправляет и не публикует сам.
- Не запрашивает пароль, cookie или токен от аккаунта.
- Не выполняет массовые рассылки, автоматические лайки и подписки.

Если содержимое ссылки недоступно, навык скажет об этом и попросит скриншот или текст, а не будет описывать невидимые публикации.
