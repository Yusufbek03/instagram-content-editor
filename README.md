# Instagram Content Editor

Навык для ChatGPT/Codex по Instagram: контент, услуги, монетизация, продажи и подключение интеграций. Версия 2.1.

**После установки достаточно дать ссылку или @username и задачу.** Агент читает
доступные публичные метаданные, при наличии браузера смотрит доступные публикации
и отвечает на основании увиденного. 20 редакционных режимов продолжают работать
по текстам, изображениям, видео и статистике пользователя.

```text
Мой Instagram @username. Разбери шапку профиля и предложи три улучшения.
```

| Режим | Что доступно | Что требуется |
|---|---|---|
| Публичный | Фактически полученные метаданные, доступный контент через браузер агента | Ссылка/username, сеть; для скрипта Python 3.9+ |
| Собственный OAuth | Проверенный аккаунт, до 12 своих публикаций: подпись, тип, дата, ссылка | Business/Creator, собственное Meta app, HTTPS callback, OS vault |
| Insights | **Не реализованы**; предусмотрен план официального расширения | Отдельные права и review Meta либо предоставленные пользователем выгрузки |

Публичный профиль — **не авторизация**. URL не открывает скрытую статистику.
Instagram может вернуть экран входа/ограничение доступа: тогда агент обозначит
частичный результат и попросит материалы для недоступной части. Полный автоматический
аудит любого профиля не гарантируется. Скрипт не обходит блокировки и не использует cookies.

## Возможности

20 режимов, объединённых в две группы.

### Контент и редактура

| Режим | Что делает |
|---|---|
| `ig-profile` | Разбор и улучшение профиля: имя, описание, аватар, ссылки, закреплённые публикации |
| `ig-reel` | Сценарий короткого видео: три варианта начала, текст на экране, план кадров |
| `ig-viral` | Исследование примеров похожих авторов с источниками и датами наблюдения |
| `ig-caption` | Подпись: первая строка, продолжение, одно действие, хештеги по теме |
| `ig-carousel` | Карусель: обложка, контекст, шаги, итог, следующее действие |
| `ig-story` | Последовательность Stories: повод, содержание, взаимодействие, завершение |
| `ig-plan` | Контент-план с метрикой проверки и нужными материалами |
| `ig-human` | Редактура текста: ясность, голос автора, убрать лишнее |
| `ig-comment` | Черновики комментариев без спама и выдуманного опыта |
| `ig-reply` | Ответы на комментарии с разбором по типам |
| `ig-dm` | Черновик личного сообщения с понятным поводом |
| `ig-repurpose` | Переработка длинного материала в несколько форматов |
| `ig-audit` | Аналитика: наблюдения с доказательствами и проверяемые эксперименты |

### Бизнес и подключения

| Режим | Что делает |
|---|---|
| `ig-strategy` | Позиционирование, три тематические линии, план проверки на 2 недели |
| `ig-monetize` | Сравнение моделей заработка: услуги, продукты, реклама, партнёрства |
| `ig-offer` | Формулировка предложения: адресат, результат, состав, срок, ограничения |
| `ig-portfolio` | Кейсы и портфолио без подмены демо-проекта клиентским |
| `ig-sales` | Ответы на входящие, вопросы для брифа, черновик предложения |
| `ig-connect` | Проверка и подключение реально доступных интеграций |
| `ig-experiment` | Проверка гипотез: база, метрика, период, критерий решения |

> Обозначения `/ig-*` — текстовые названия режимов, а не зарегистрированные системные команды.

## Установка и запуск

1. **Codex (macOS/Linux):** установите папку в каталог навыков. Команда откажется
   перезаписывать существующую установку; если она уже есть, обновите её отдельно,
   предварительно сохранив локальные правки.

   ```bash
   mkdir -p "${CODEX_HOME:-$HOME/.codex}/skills"
   git clone https://github.com/Yusufbek03/instagram-content-editor.git "${CODEX_HOME:-$HOME/.codex}/skills/instagram-content-editor"
   ```

2. Перезапустите/обновите список навыков своего агента. Напишите:
   «Используй instagram-content-editor. Мой профиль @username. Разбери описание».
   Для других агентов поместите папку в их каталог skills. В интерфейсах ChatGPT/Atlas
   наличие загрузки файлов само по себе не устанавливает исполняемый skill: требуются
   поддержка навыков и инструменты среды. Без Python остаётся браузер/материалы пользователя.

3. Для отдельной проверки публичного чтения из папки навыка:

   ```bash
   python3 scripts/instagram.py '@instagram'
   python3 scripts/instagram.py 'https://www.instagram.com/instagram/'
   ```

   Зависимости устанавливать не нужно. Вывод — JSON: профиль, источник, время наблюдения,
   список фактов, ограничения и следующий шаг. `partial` означает доступные метаданные,
   а не полный профиль; `unavailable`/exit code 2 — штатное отсутствие данных.
   Визуальные оценки и анализ публикаций делает агент по реально прочитанному браузером
   или предоставленному контенту. Скрипт не сохраняет профиль и не создаёт постоянную сессию.

4. Для собственного аккаунта используйте отдельную
   [инструкцию официального OAuth](references/meta-oauth.md).
   Публичный режим от настройки OAuth не зависит. Локальный OAuth требует собственного
   Meta app; общий сервис «одна кнопка для всех» не развёрнут. Ни пароль, ни токен,
   ни App Secret не нужно присылать агенту.

## Тестирование

```bash
python3 -m unittest discover -s tests -v
```

Тесты не требуют токенов, аккаунта и внешней сети; callback проверяется на loopback. CI запускает их на Python 3.9 и 3.12.
Проверяются URL/SSRF, отказ доступа, лимиты и неполные данные, OAuth state/истечение/replay,
ошибки API, сверка аккаунта и отсутствие токена в выводе. Полный OAuth-вход в реальную
Meta app требует отдельной настройки и не подтверждён автоматическими тестами.

## Принципы работы

Навык разделяет три вещи: наблюдаемые факты, твои слова и предположения. Недостающий факт помечается как `[уточнить факт]` или текст пишется без него.

Чего навык не делает:

- Не обещает рост, вирусность, продажи или конкретные охваты.
- Не выдумывает опыт, клиентов, результаты и цифры.
- Не выдаёт редакционную оценку за измеренную эффективность.
- Не считает малый объём данных доказанной закономерностью.
- По умолчанию готовит черновики — ничего не отправляет и не публикует сам.
- Не запрашивает пароль, cookie или токен от аккаунта.
- Не выполняет массовые рассылки, автоматические лайки и подписки.

Если содержимое ссылки недоступно, навык скажет об этом и попросит скриншот или текст, а не будет описывать невидимые публикации.
