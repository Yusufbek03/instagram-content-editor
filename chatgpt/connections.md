# Доступ к Instagram в ChatGPT

Версия для ChatGPT использует инструменты, уже доступные в текущем чате.
Пакет не устанавливает браузер, сервер или дополнительные права Instagram.

| Вход | Что можно делать |
|---|---|
| Ссылка / @username и доступное веб-чтение | Разобрать фактически видимые публичные сведения |
| Поисковый фрагмент | Использовать как ограниченный источник с оговоркой об актуальности |
| Скриншоты / тексты / видео пользователя | Разобрать наблюдаемое содержимое |
| Скриншоты / выгрузка Insights | Анализировать предоставленные метрики, указав период и источник |
| Отдельно авторизованный официальный коннектор | Только поддерживаемое чтение проверенного аккаунта |

Нельзя превращать ссылку в доказательство авторизации или обещать скрытые Insights.
Не запрашивай пароли, cookies, OAuth codes, токены и App Secret. Не обходи блокировки
и не требуй настройки Python/Meta app у конечного пользователя.

Если прямое чтение закрыто, сначала ответь по доступной части, затем попроси только
недостающие материалы. Если запроса достаточно для сценария или плана, выполни его
без обязательного чтения аккаунта. Установка и начало работы не должны превращаться
в длинную техническую инструкцию.
