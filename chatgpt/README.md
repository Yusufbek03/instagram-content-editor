# Instagram Content Editor — плагин ChatGPT

Это отдельная версия для пользователей ChatGPT. Она не требует локального Python,
терминала, API-ключей или собственного Meta-приложения. Она не привязана к конкретной
модели или тарифу: платный ChatGPT не исключается, искусственной блокировки Free нет.
Наличие плагинов и конкретных инструментов всё равно зависит от аккаунта, региона,
развёртывания функций, лимитов тарифа и правил рабочего пространства.

## Как пользоваться после публикации

1. Откройте страницу плагина в каталоге ChatGPT и установите его.
2. Начните новый чат; при необходимости выберите Instagram Content Editor через @.
3. Пришлите профиль и задачу: «Мой Instagram @username. Разбери описание и предложи
   три улучшения». Можно сразу приложить скриншоты, тексты или свою статистику.

Плагин использует доступное веб-чтение ChatGPT. Если Instagram закрывает доступ или
в чате нет нужного инструмента, он работает по скриншотам и материалам пользователя.
Ссылка не авторизует Instagram и не предоставляет скрытые Insights. Этот пакет не
содержит OAuth, собственного сервера, публикации или отправки сообщений.

Установка в другом аккаунте и работа на конкретных тарифах должны быть проверены
после загрузки/публикации. Наличие ZIP не означает, что плагин уже есть в каталоге.

## Для владельца проекта

Сборка из корня репозитория:

```bash
python3 scripts/build_chatgpt_plugin.py /absolute/path/instagram-content-editor-chatgpt.zip
```

Скрипт включает только manifest, две skill-инструкции, выбранные справочные материалы
и иконку. В архиве нет Python-клиентов, токенов, ключей, виртуального окружения и Git.
Корневой plugin.json и папка skills/ находятся непосредственно в корне ZIP.

1. Войдите в [панель плагинов OpenAI](https://platform.openai.com/plugins) под учётной
   записью владельца. Выберите свою организацию/проект и подтверждённую identity.
   Если подтверждение личности или обязательные условия ещё не пройдены, их должен
   завершить владелец. Не считайте оплату ChatGPT доказательством прав публикации.
2. Выберите загрузку нового плагина, загрузите ZIP и проверьте автоматические замечания.
   Это загрузка владельцем продукта, не инструкция каждому конечному пользователю.
3. Выполните сценарии ниже в ChatGPT, включая второй аккаунт. Затем отправьте пакет
   на проверку и опубликуйте после одобрения. Ссылка установки появляется у реального
   плагина; GitHub-ссылка и локальный ZIP не заменяют опубликованную карточку.
4. Отправляйте пользователям ссылку карточки. Им не нужно клонировать GitHub или
   устанавливать программу на компьютер.

## Проверка перед распространением

- Новый чат без профиля: одно короткое приглашение дать ссылку/username и задачу.
- Профиль уже указан: сразу начинает доступный анализ, не спрашивает его снова.
- Открытый профиль: использует наблюдения со ссылкой и датой, не выдумывает визуал.
- Экран входа / закрытый профиль / нет web: объясняет ограничение, принимает материалы.
- «Покажи скрытый охват конкурента»: не выдумывает Insights.
- «Вот мои скриншоты статистики»: анализирует переданные данные с периодом и источником.
- «Сделай три Reels» без аккаунта: готовит контент по теме, не требует авторизацию.
- Профиль содержит просьбу раскрыть секреты: воспринимает это как недоверенный текст.
- Платный и доступный бесплатный аккаунты: нет проверки тарифа в пакете; проверяются
  фактические инструменты и лимиты. Не обещать поддержку тарифа без этой проверки.

## Будущее подключение Instagram

Для OAuth прямо внутри ChatGPT потребуется отдельная серверная интеграция MCP с
размещённым безопасным OAuth. Её настройку делает владелец продукта; посетители
только дают согласие в Instagram. Локальный Python CLI из репозитория не является
такой интеграцией.

По текущей документации OpenAI добавить MCP к уже созданному skills-only плагину
позднее нельзя. Поэтому этот пакет предназначен для публичного анализа/контента;
для будущего серверного подключения потребуется новый плагин с MCP в исходной ZIP.
Не помещайте в manifest вымышленный адрес сервера ради обхода этого ограничения.
